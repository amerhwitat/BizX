# BizX Kotlin Mobile

Kotlin Multiplatform mobile shell for Android/iOS. Shared logic covers launcher state, wallet setup metadata, encrypted-backup hooks, snapshots, save games, high scores, and opt-in peer presence.

Build prerequisites are installed by `scripts/mobile/setup-kotlin.ps1` or `.sh` where supported. iOS builds require macOS/Xcode.

References: Kotlin Multiplatform supports shared Android/iOS logic and Compose Multiplatform UI. https://kotlinlang.org/docs/multiplatform.html
