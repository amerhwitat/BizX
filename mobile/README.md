# BizX Mobile Cross-Platform Layer

Mobile contracts shared by Android/Kotlin and Apple/Swift implementations. Feature families: game, NetworkUnified, launcher, InternetScanner, AssetBrowser, crypto, web, 3D, game-assets, game-store, network, rendering and scripts.

Use platform-native lifecycle, permissions, secure storage, networking and rendering adapters. Browser-only and desktop-only capabilities are not silently elevated on mobile.
