# BizX Game Store + Storyboard Library

The store is an engine-neutral catalog for 2D, 3D and experimental 4D storyboard/game content.

## Content policy

Only assets with a verified reuse license are eligible for automatic import. Public visibility alone is not treated as permission to copy. Each item stores source URL, license, attribution requirements, version, checksum and supported engines.

Preferred sources include CC0/public-domain collections and free/open game-art repositories. OpenGameArt supports multiple free licenses, including CC0 and CC-BY variants; every item must still be checked individually.

## Item types

- 2D: sprites, tiles, UI, backgrounds, storyboards, concept art
- 3D: models, environments, materials, HDRIs, animations
- 4D: time-indexed scenes, volumetric/temporal storyboards, multi-frame state sequences
- game templates: quests, scenes, dialogue graphs, level layouts and prototype mechanics

## Store economics

The catalog supports `free`, `donation`, and `low_price` metadata. BizX does not assume a particular payment processor. Purchases are represented as checkout intents; crypto payment is only finalized after explicit user confirmation through a supported wallet/provider.

## Recommended public sources

- OpenGameArt — free/open game artwork under multiple licenses.
- Poly Haven — CC0 models, textures and HDRIs; API access must follow its current terms.
- Smithsonian Open Access — public/CC0-designated digital collections where the individual item permits reuse.

## No unauthorized scraping

Use official APIs, feeds, downloads, or provider-approved endpoints where available. Do not bypass robots.txt, rate limits, access controls, paywalls, DRM, or site terms.
