# BizX Retro Media Build

The retro matrix uses native media containers per machine family.

| Target | Native image |
|---|---|
| Atari 8-bit | ATR |
| Apple II | DSK |
| ZX Spectrum | TAP |
| Amstrad CPC | DSK |
| MSX | DSK |
| BBC Micro | SSD |
| TRS-80 | DSK |
| Amiga 500 | ADF |
| Atari ST | ST |

Checked-in non-Commodore images are deterministic native/structural containers. They are not marked as flawless executable releases until each target has a native loader/compiler path and an emulator assertion.

The Commodore C64 edition remains the executable baseline. No proprietary ROM images are redistributed.
